# Student Performance Analysis Dashboard (Power BI)

## 📌 Project Overview
This project analyzes student academic performance using Power BI. The dashboard provides insights into average scores across math, reading, and writing, segmented by gender, ethnicity, parental education level, and test preparation course.

## 🎯 Objectives
- Analyze overall student performance
- Identify factors impacting academic scores
- Compare performance across demographics
- Provide actionable insights for educators

## 🛠 Tools & Technologies
- Power BI
- Excel / CSV
- DAX

## 📊 Key Metrics
- Student Count
- Average Math Score
- Average Reading Score
- Average Writing Score
- Average Score Percentage

## 📈 Dashboard Insights
- Students who completed test preparation courses scored higher on average
- Female students showed slightly better performance overall
- Higher parental education level correlates with better student scores
- Performance varies across different ethnic groups

## 🚀 How to Use the Project
1. Download the .pbix file from the repository  
2. Open it using *Power BI Desktop*  
3. Load or refresh the dataset if required  
4. Use slicers to explore performance across different categories
